# CV folder

Put ONE PDF of your CV here. The website shows a **Download CV** button for it within ~2 minutes.

- **Add / replace:** Add file → Upload files → drop the PDF → Commit changes. Then delete the old PDF.
- **Take down:** delete the PDF. The button disappears by itself.
- Only you can do this, because only you can edit this GitHub repository.

Do not delete this README, or the folder disappears.
